# 🛒 Grocery Store API

REST API магазина продуктов на Django REST Framework: каталог, корзина и авторизация по токену.

## ✨ Возможности

- 📦 **Каталог**: категории, подкатегории и продукты (название, slug, цена, картинка)
- 🖼️ **3 размера картинок** (small 100px, medium 300px, large 800px) создаются автоматически из одного файла
- 🛠️ **Админка**: добавление, изменение и удаление каталога
- 🛍️ **Корзина**: добавить, изменить количество, удалить, очистить, посмотреть итог (количество и сумма)
- 🔐 **Токен-авторизация**: регистрация и вход
- 📖 **Swagger** документация
- 🧪 **Автотесты** (pytest) и 🗂️ **фикстуры**

## 🧰 Технологии

Python 3.12 · Django · DRF · drf-spectacular · django-imagekit · Pillow · SQLite · pytest

## 🚀 Запуск локально

```bash
# 1. Клонировать проект
git clone <ссылка-на-репозиторий>
cd <папка-проекта>

# 2. Виртуальное окружение
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux / macOS

# 3. Зависимости и база
pip install -r requirements.txt
python manage.py migrate

# 4. Тестовые данные (3 категории, 6 подкатегорий, 12 продуктов)
python manage.py loaddata initial_data

# 5. Админ и запуск
python manage.py createsuperuser
python manage.py runserver
```

На Windows вместо `python` можно писать `py`.

Если нет картинок в `media/`, создай их командой `python make_images.py` и повтори `loaddata`.

## 🔌 Эндпоинты

### 🔐 Авторизация
| Метод | URL | Описание |
|---|---|---|
| POST | `/api/auth/register/` | регистрация, возвращает токен |
| POST | `/api/auth/login/` | вход, возвращает токен |

Токен передаётся в заголовке: `Authorization: Token <токен>`

### 📦 Каталог (без авторизации, с пагинацией `?page=N`)
| Метод | URL | Описание |
|---|---|---|
| GET | `/api/categories/` | категории с подкатегориями |
| GET | `/api/products/` | продукты |
| GET | `/api/products/<slug>/` | один продукт |

Поле `images` у продукта содержит ссылки `small`, `medium`, `large`.

### 🛍️ Корзина (только с токеном и только своя)
| Метод | URL | Описание |
|---|---|---|
| GET | `/api/cart/` | состав, `total_quantity`, `total_price` |
| DELETE | `/api/cart/` | очистить корзину |
| POST | `/api/cart/items/` | добавить: `{"product_slug": "syr-gauda", "quantity": 2}` |
| PATCH | `/api/cart/items/<id>/` | изменить количество: `{"quantity": 5}` |
| DELETE | `/api/cart/items/<id>/` | удалить позицию |

- Повторное добавление продукта увеличивает количество
- Без токена: `401`, чужая позиция: `404`

## 📖 Как пользоваться Swagger

1. Открыть `/api/docs/`
2. Получить токен через `register` или `login`
3. Нажать **Authorize** и ввести `Token <ваш_токен>`

## 🧪 Тесты

```bash
pytest
```

Проверяют: список категорий и продуктов (GET), регистрацию, вход, добавление в корзину (POST), итоги корзины и права доступа.

## 🔢 Алгоритмическое задание

Файл `repeated_numbers.py` выводит первые `n` элементов последовательности, где число `k` повторяется `k` раз (`1 2 2 3 3 3 ...`), слитно.

```bash
python repeated_numbers.py
```

| n | Вывод |
|---|---|
| 7 | `1223334` |
| 10 | `1223334444` |
| 15 | `122333444455555` |
